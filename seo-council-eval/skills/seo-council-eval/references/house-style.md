# House style (example)

This file is an **example**, not a rule set the skill enforces. The council writes
a client-facing report, and most agencies have their own conventions for how that
report should read. Replace everything below with yours, or delete this file if you
do not want a house style applied.

The report step in `SKILL.md` looks for these conventions and applies them if they
are present. Nothing here is enforced by a script.

## How to use this file

Uncomment the block below and edit it to your own conventions. While it stays
commented, the skill treats it as "no house style on file" and writes a plainly
formatted report.
