# Notice

This skill evaluates SEO copy through a panel of analytical lenses. Each lens is
built from the published frameworks of a named SEO practitioner.

**These lenses are analytical perspectives, not the people they are named for.**

- No named individual has reviewed, endorsed, contributed to, or is affiliated
  with this skill.
- No named individual has seen any page this skill scores.
- The scores and findings a run produces are the output of this tool applying
  published ideas. They are not the opinions, advice, or work of the named
  practitioners, and must never be presented to a client or anyone else as though
  a named person reviewed their page.
- This skill is an evaluation tool. It is not a consultation service, and it is not
  a substitute for one.

The report template and an automated gate (`scripts/check-attribution.cjs`) enforce
the same rule inside the reports the skill writes: seats appear as lenses, and a
disclaimer travels with every report. That gate is a required step of every run.

## If you are named in this skill

`PERSONAS.md` lists every named seat, its sources, and how to ask for your seat to
be removed or amended. Any such request is acted on promptly and without argument.
You do not need to explain or justify it.
