# Personas

This council evaluates SEO copy through a panel of analytical lenses. Each lens is
built from the published frameworks of a named practitioner, so that the seats
notice genuinely different things about a page. This file is the complete roster
and the removal process for it.

## What these lenses are, and are not

Each seat below is an analytical perspective derived from a practitioner's public
work. It is **not** that person. None of the named individuals has reviewed,
endorsed, contributed to, or is affiliated with this skill, and none has seen any
page it scores. The per-dimension scoring notes in each persona file are this
council's application of published ideas, not statements the practitioner has made.
The skill is an evaluation tool, not a consultation service.

## Removal and amendment

If you are one of the people named below and you would prefer not to be, that is
enough. You do not need to explain or justify it.

Contact **who@whodigitalstrategy.com** to request that your seat
be removed or amended. The commitment is to act on any such request promptly and
without argument: a removal takes the persona file out of `personas/`, which also
removes the seat from every future run, since the roster reads from that directory.
A correction to how your positions are characterised will be made on the same terms.
