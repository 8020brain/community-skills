# Logo Brief

Built by **Sandi Walsh** and shared free with the Ads2AI community.

## How to use it

Install it with `claude plugin install logo-brief@a2ai-community`, then ask for "a logo brief
for [client]". Claude fills in what your brain already knows about the client and their
website, asks you only for what's missing, and saves the brief with the client's files. Paste
it into Claude Design (claude.ai/design) to get the logo concepts.

## A few things to know

- **It always asks whether the client already has a logo**, so the first round isn't wasted.
- **It never sends anything.** Any covering email to the client is a draft for you to send.
- **A filled-in brief names the client**, so don't share one in a group or a public post. The
  blank template is safe to share.
