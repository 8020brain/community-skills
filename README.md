# A2AI Community Skills

Community-contributed skills for the [8020brain](https://8020brain.com) template.

## Installing a Skill

From your brain, run:

```
/plugin install skill-name@a2ai-community
```

## Available Skills

Share your skill in the [A2AI Community](https://mikerhodes.circle.so) and Mike will review and add it here.
