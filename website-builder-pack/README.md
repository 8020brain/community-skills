# Website Builder Skill Pack

Ten Claude skills that take you from blank folder to launch-ready WordPress website. No developer needed. No page builders. Just clean, custom-coded WordPress built through a conversation with Claude.

## Getting Started

Inside this folder there is a folder called `guide`. Open it and you will find two versions of the full walkthrough:

- **build-your-website-with-ai.html** - double-click this to read it in your browser
- **build-your-website-with-ai.md** - plain text version if you prefer

The guide covers everything: installing Claude Code, setting up Local WP, installing the skills, building your site, and going live.
