What's Included

Ten skills that handle every stage of the build. Ten stages in total. Use them together or one at a time.

The Website Builder Skill Pack is a set of Claude skills that guide you through building a complete WordPress website from scratch. You install the skills into Claude Code, describe your business, and Claude handles the technical work: planning the pages, generating the theme files, building each page template, writing the copy, and running a pre-launch check before you go live.

No developer needed. No page builders. No drag-and-drop editors. Just clean, custom-coded WordPress built through a conversation with Claude.

The skills work together as a complete pipeline, or you can use any of them individually if you only need one part of the process.

website-builder Full Build Orchestrator

Runs the complete website build from start to finish. Works through ten stages: Discovery, Site Plan, SEO Structure Analysis, Theme, Pages, Keyword Planning, Copy, SEO/AEO Audit, Security Audit, and Launch Check. Confirms with you at each stage before moving on. This is the skill to use if you want to build an entire site in one workflow.

Trigger: "Build me a website for my business"

site-planner Site Planner

Takes your business details and produces a complete site plan: which pages you need, how they're structured, what the navigation looks like, and the order to build them in. Gives you one clear recommendation per decision, no options overload.

Trigger: "Plan my website"

theme-scaffolder Theme Scaffolder

Generates all the files needed for a working WordPress theme, style.css, theme.json, templates, header, footer, and starter patterns. Defaults to block themes (Full Site Editing). You copy the output into your Local WP themes folder and activate it.

Trigger: "Create a WordPress theme for my business"

page-builder Page Builder

Builds individual page templates with conversion-optimised layouts. Covers homepage, about, services, individual service pages, contact, and landing pages. Each layout follows CRO best practices, clear value proposition above the fold, strategic CTA placement, trust signals near conversion points.

Trigger: "Build me a homepage for [business]"

content-writer Content Writer

Writes ready-to-paste copy for every page, headlines, body text, CTAs, service descriptions, about sections, and testimonial frameworks. Focuses on conversion: benefit-led headlines, customer-focused body copy, specific CTAs. After generating copy it automatically runs the superhuman-writer pass.

Trigger: "Write the copy for my homepage"

superhuman-writer Superhuman Writer

Takes any copy and makes it sound like a real person wrote it. Removes AI patterns, fixes rhythm, adds human texture. Runs automatically after the content-writer, but you can also use it standalone on any text, emails, service descriptions, bios, anything. If you've set up a voice-dna.md file it will write in your specific voice.

Trigger: "Make this sound human" or "Rewrite this copy"

seo-aeo SEO / AEO Optimiser

Runs at three points in the build. After the site plan: analyses page hierarchy, topical authority, internal linking, and URL structure. Before copy is written: produces a keyword plan with a primary keyword, intent classification, and supporting keywords for every page. After copy is written: audits every page for on-page SEO and AEO quality, scores each page out of 10, generates schema markup (JSON-LD), and produces a fix list. Target is 8/10 per page before launch.

Trigger: "Keyword research for my site" or "SEO audit"

launch-checklist Launch Checklist

Produces a personalised pre-launch audit covering content completeness, SEO basics, performance, mobile responsiveness, conversion readiness, security, legal compliance, and go-live technical steps. Every item is tagged BLOCKER, IMPORTANT, or NICE-TO-HAVE so you know exactly what to fix before going live.

Trigger: "Give me a pre-launch checklist"

Before You Start

Two tools to install and a few things to have ready.

Tools You Need

1

Claude Code

The command-line tool that lets Claude work directly with files on your computer. This is what activates the skills.

Install it at claude.ai/code. Once installed, type claude in your terminal to confirm it's working.

2

Local WP

A free tool that runs WordPress on your computer. No hosting account or domain needed to start.

Download it at localwp.com, install it, and create a new site. Write down your WordPress admin username and password.

What to Have Ready

  • Your business name and what you do
  • Who your customers are and what they're looking for
  • The main goal of your website (leads, sales, bookings, or credibility)
  • Brand colours as hex codes, if you have them (e.g. #1E40AF). If not, Claude will suggest some.
  • Any existing copy, about page text, service descriptions, testimonials, team bios. Even rough notes help.
No coding knowledge needed
Claude handles all the technical parts. Your job is to describe your business and tell Claude what looks right.

Step 3

Full Build

Use the website-builder skill to run the entire process from start to finish.

The website-builder skill is the master skill. It runs ten stages in one guided workflow: Discovery, Site Plan, SEO Structure Analysis, Theme, Pages, Keyword Planning, Copy, SEO/AEO Audit, Security Audit, and Launch Check. Claude confirms with you at each stage before moving on.

"Build me a website for my business."

Claude will ask for your business details, then work through each stage in order.

If you want to skip a stage, for example, you'll write your own copy, just tell Claude. It will move to the next stage without issue.

Skill

Site Planner

Works out what pages you need, how they're structured, and what to build first.

What It Does

Takes your business description and produces a complete website plan. It recommends a theme type, builds a page list tailored to your business type, creates a site map, recommends your navigation, and gives you a prioritised build order.

One clear recommendation per decision. It won't give you a list of options and ask you to choose, it will tell you what to do.

How to Use It

"Plan my website. I run [business name]. We [what you do] for [who]. The main goal is [leads / sales / bookings / credibility]."
What you get back
  • Theme type recommendation with a one-line reason
  • Page list with purpose and priority for each page
  • Site map showing the full structure
  • Main menu and footer menu recommendations
  • Build order, which page to tackle first, second, third
Save the output. The page list and build order are your reference for the rest of the build.
Skill

Theme Scaffolder

Generates all the WordPress theme files you need, ready to install in Local WP.

What It Does

Creates a complete WordPress theme skeleton. For block themes (the default): style.css, theme.json with your colours and fonts, page templates, header and footer, and a starter hero pattern. For classic themes: the full PHP template set.

All code follows WordPress coding standards. Colours are locked down in theme.json so they can't be accidentally changed in the editor.

How to Use It

"Create a WordPress block theme for [business name]. Primary colour: [hex]. Secondary colour: [hex]."

If you don't have brand colours, just tell Claude your industry and it will suggest appropriate ones.

What you get back
  • All theme files with complete contents, ready to copy
  • Installation instructions for Local WP
  • A list of what to customise next

Installing the Theme

Copy the theme folder Claude creates into your Local WP themes directory:

  • Windows: C:\Users\[you]\Local Sites\[site]\app\public\wp-content\themes\
  • Mac: ~/Local Sites/[site]/app/public/wp-content/themes/

Then go to Appearance > Themes in WordPress and activate it.

Skill

Content Writer

Writes the copy for every page, then automatically runs a human voice pass.

What It Does

Writes ready-to-paste website copy section by section: headlines, subheadlines, body copy, service descriptions, about text, CTA buttons, and supporting text. Every piece is focused on conversion, benefit-led headlines, copy that speaks to the customer, CTAs that drive action.

After writing the copy, it automatically passes it through the superhuman-writer to remove AI patterns and make it sound human. You get one final version, not two drafts.

How to Use It

"Write the copy for my [page name]. We're [business description]. Target customers: [who]. Main differentiator: [what makes you different]. CTA: [action]."

The more context you give, the better the copy. If you have existing copy, testimonials, or rough notes, share them, Claude will build around what already works.

Voice DNA
If you have a voice-dna.md file set up, the voice pass will write in your specific brand voice. If you also have a customer avatar or audience document, share it alongside your brief. Claude reads both and uses them to write copy that sounds like you and speaks directly to your ideal customer.
What you get back

Skill

Superhuman Writer

Makes any copy sound like a real person wrote it.

What It Does

Takes copy and removes the patterns that make it obvious AI wrote it: even paragraph lengths, hedging language, generic transitions, banned buzzwords, and rhythm that sounds like a press release. It rebuilds the writing with varied sentence lengths, natural contractions, and human texture.

It runs automatically after the content-writer, but you can also use it on any copy at any time, emails, service descriptions, bios, social posts.

Using It Standalone

Paste copy and ask Claude to fix it:

"Make this sound human: [paste your copy]"

Or ask it to write from scratch:

"Write a [homepage hero / about section / service description] for [brief]. Make it sound human."

With Voice DNA

If you've set up a voice-dna.md file, the superhuman-writer reads it before writing. This means it won't just sound human, it will sound like you.

It won't invent facts
If copy needs a specific statistic, story, or named example that wasn't provided, the skill will ask rather than make something up. Good copy needs real details, have them ready.
Skill

SEO / AEO Optimiser

Keyword planning before you write, and on-page scoring after.

What It Does

This skill runs at two points in the build. Before writing, it maps keywords to every page so the content-writer knows exactly what to target. After writing, it audits every page for SEO and AEO quality, scores them, generates schema markup, and tells you what to fix.

AEO, Answer Engine Optimisation, makes your pages readable by AI search tools like Google AI Overviews, ChatGPT, and Perplexity. Same content, structured so it can be extracted and cited.

Mode 0, Site Structure Analysis (after site plan)

Run this immediately after the site-planner confirms your page list. Before a single page is built, Claude reviews the proposed structure for SEO effectiveness.

"Analyse my site plan for SEO. Here's the plan: [paste site-planner output]"
What you get back
  • Topical authority assessment, whether the page set is deep enough to rank
  • Page hierarchy check, any orphaned or hard-to-reach pages
  • Internal linking map, which pages should link to which
  • URL slug recommendations for every page
  • Missing pages flagged by priority, pages that would help SEO but aren't in the plan
  • A one-paragraph verdict on whether the structure is ready to build
Fix structure before you build
It's much easier to add or restructure pages at this stage than after the theme and templates are built. Take the recommendations seriously before moving to Stage 3.

Mode 1, Keyword Planning (before copy)

Run this after the site plan and before writing any copy.

"Keyword research for my site. Here are my pages: [list from site plan]."
What you get back
  • Primary keyword for every page
  • Intent classification (informational, commercial, transactional, navigational)
  • 3-5 supporting keywords per page
  • Recommended content format based on what's ranking

Mode 2, On-Page Audit (after copy)

Run this after the content-writer and superhuman-writer have finished. Pass in the finished copy for each page.

"SEO audit my copy. [paste or reference the copy files]"
What you get back
  • Score out of 10 for every page (target: 8/10 minimum before launch)
  • Fixes required and fixes recommended for each page
  • Complete JSON-LD schema markup for each page type
  • FAQ section assessment and improvements

Skill

WordPress Security Audit

Scans your theme code for vulnerabilities before upload. Runs automatically at Stage 9.

The wordpress-security-audit skill scans the theme code Claude generated and produces a severity-rated report with exact fixes. It runs at Stage 9 of the full build, before the launch checklist.

It checks three areas:

  • JavaScript: unsafe DOM writes, XSS vectors, unvalidated URL parameters
  • PHP theme files: SQL injection, XSS, CSRF, missing nonces, dangerous functions, ABSPATH guards
  • Theme directory: no .sql files, backup folders, or log files left in the theme

All Critical and High findings must be resolved before uploading to live hosting.

Trigger phrase (standalone use):

"Security audit my WordPress theme. The theme is at [path]."

Production Audit (After Going Live)

The wordpress-production-audit skill handles server-level checks that only apply once your site is on live hosting. Run it after migrating from Local WP.

It checks:

  • wp-config.php: weak credentials, debug settings, secret keys, table prefix
  • .htaccess: git exposure, uploads PHP execution, security headers, CSP
  • Exposed files: wp-config.php, .env, debug.log, .git/config must return 403/404
  • Meta security: user enumeration, admin username, hardcoded credentials

Trigger phrase:

"Run a production security audit on my live site."

Produces a personalised pre-launch checklist based on your site type, page list, and primary goal. Covers eight areas: content completeness, SEO basics, performance, mobile responsiveness, conversion readiness, security, legal compliance, and go-live technical steps.

Every item is tagged so you know what to prioritise:

How to Use It

"Give me a pre-launch checklist. It's a [business type] site with these pages: [list them]. Primary goal: [leads / sales / bookings]."
What you get back

  • Recommended plugins list

Most common launch mistake
WordPress has a setting called "Discourage search engines from indexing this site" that's sometimes turned on during development. The checklist will flag this as a BLOCKER. Check it under Settings > Reading before going live.

Recommended Plugins

The plugin types every WordPress site needs, with a couple of options per category.

WordPress core handles the basics. Plugins cover the rest. Install only what you need. Every plugin adds load time, and most sites only need five or six.

TypeWhy You Need ItOptions
SEO Title tags, meta descriptions, schema markup, XML sitemaps Rank Math (free), Yoast SEO (free)
Caching Speeds up the site for real visitors WP Rocket (paid), LiteSpeed Cache (free), W3 Total Cache (free)

Step 5

Go Live

Migrate from Local WP to hosting and publish your site.

What You'll Need

  • A domain name, buy from Namecheap, Cloudflare, or your preferred registrar
  • WordPress hosting, Cloudways (best performance), SiteGround (beginner-friendly), or Krystal (UK-based) all work well

Migrating from Local WP

1

Export from Local WP

Right-click your site in Local WP and choose Export. This creates a ZIP file of your entire site.

2

Set up hosting

Create a hosting account and install WordPress. Your host will have a one-click WordPress installer.

3

Import your site

Install UpdraftPlus (free) or Duplicator on your new hosting. Use it to import the ZIP file from step 1. Note: All-in-One WP Migration requires a paid upgrade to import.

4

Update your domain

Point your domain's DNS to your hosting. Your hosting provider will give you the nameservers to use. DNS changes can take up to 48 hours.

5

Install SSL

Most hosts install SSL automatically. If not, use Let's Encrypt (free) via your hosting control panel.

6

Update URLs

Run a search-and-replace to update all references from your local URL (e.g. mysite.local) to your live domain (e.g. mysite.com). Use the Better Search Replace plugin.

After Going Live

  • Test your contact form on the live site
  • Check the site on your phone
  • Submit your sitemap to Google Search Console at yourdomain.com/sitemap.xml
  • Set up automatic backups (most hosts provide this, or use UpdraftPlus)
  • Check for any 404 errors in the first week
  • Push your theme folder to a private GitHub repository. If something breaks after a plugin update or edit, you can restore from there.
You're live

Troubleshooting

The most common issues and how to fix them.

Theme not showing in Local WP

The theme folder must be copied into the correct location and contain a valid style.css with a theme header. Check the path:

  • Windows: C:\Users\[you]\Local Sites\[site]\app\public\wp-content\themes\
  • Mac: ~/Local Sites/[site]/app/public/wp-content/themes/

After copying, go to Appearance > Themes in WordPress and click Activate. If the theme still doesn't appear, check that the folder name contains no spaces and that style.css exists in the root of the theme folder.

Contact form not sending emails

Local WP does not send real emails by default. Install the WP Mail SMTP plugin and connect it to a mail provider (Gmail, Mailgun, or similar) to test form submissions locally. On your live site, most hosting providers handle email delivery, but WP Mail SMTP is still recommended for reliability.

Search engines blocked after launch

WordPress has a setting that blocks search engines, often turned on during development. Before going live, go to Settings > Reading and make sure "Discourage search engines from indexing this site" is unchecked. The launch checklist will flag this as a BLOCKER.

Page template not appearing in WordPress

For block themes, page templates must be in the templates/ folder inside your theme. For classic themes, they must be in the theme root and contain the correct template header comment. After adding the file, go to the page in WordPress, look under Page Attributes and select the template from the dropdown.

URLs still showing the local domain after migration

When you migrate from Local WP to live hosting, all database references to yoursite.local need updating to your live domain. Use the Better Search Replace plugin to find and replace the old URL across the entire database. Run it in dry-run mode first to preview the changes.

Something Claude generated looks wrong

See the section below on correcting the build mid-way.

Course-Correcting Mid-Build

You don't need to restart if something isn't right. Claude saves progress to website-build.md after every stage, so you can go back and fix specific parts without losing everything else.

ProblemWhat to Say
Wrong pages in the site plan "Go back to the site plan. I want to add [page] and remove [page]."
Theme colours or fonts are off "Regenerate the theme with these colours: [hex codes]."
A page template needs a different layout "Rebuild the [page name] template. I want [describe the change]."
Copy for one page isn't right "Rewrite the [page name] copy. [Describe what's wrong or what you want instead]."
The voice pass didn't sound right "Run the voice pass again on [page name] copy. [Describe the tone issue]."
A page scored below 8 in the SEO audit "Fix the SEO issues on [page name] and show me the updated copy."
You're always in control
Claude will not move to the next stage without your confirmation. If something needs changing, say so before approving the stage. You can also go back to any previous stage at any point.
